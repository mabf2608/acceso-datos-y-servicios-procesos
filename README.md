# Prácticas y Fundamentos de Java

> Colección de ejercicios, prácticas y proyectos desarrollados en Java mediante el entorno de desarrollo Eclipse.

## ¿Qué es Java?

**Java** es un lenguaje de programación de propósito general, orientado a objetos y multiplataforma, diseñado para permitir que las aplicaciones puedan ejecutarse en diferentes sistemas mediante la máquina virtual de Java (JVM). Es ampliamente utilizado en desarrollo de aplicaciones empresariales, backend, Android y software multiplataforma.

## Herramientas y conceptos trabajados

### Entorno y Desarrollo

* **Eclipse IDE:** Creación, configuración y gestión de proyectos Java mediante Eclipse.
* **JDK:** Compilación y ejecución de aplicaciones utilizando el Java Development Kit.
* **Control de versiones:** Seguimiento del código y organización de los proyectos mediante Git y GitHub.

### Programación Orientada a Objetos

* **Clases y objetos:** Definición de estructuras y creación de instancias.
* **Encapsulación:** Control del acceso a los atributos y métodos mediante modificadores de acceso.
* **Herencia y polimorfismo:** Reutilización de código y comportamiento dinámico de los objetos.
* **Interfaces y clases abstractas:** Definición de contratos y estructuras comunes entre diferentes clases.

### Programación y Lógica

* **Estructuras de control:** Uso de condiciones (`if/else`, `switch`) y bucles (`for`, `while`, `do-while`).
* **Métodos y funciones:** Organización del código mediante métodos reutilizables y parámetros.
* **Arrays y colecciones:** Almacenamiento y manipulación de conjuntos de datos.
* **Manejo de excepciones:** Gestión de errores mediante `try`, `catch`, `finally` y excepciones personalizadas.
